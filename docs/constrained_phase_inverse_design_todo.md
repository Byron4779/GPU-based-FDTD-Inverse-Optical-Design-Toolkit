# 约束式相位逆设计目标清单

## 1. 目标

在现有二维 TMz 逆设计示例上实现：

- 在指定单频 `f0`，出射复透射系数相对空单元参考场达到 180° 相位。
- 暂不区分“延迟 180°”和“超前 180°”；二者按模 `2π` 视为相同。
- 相位作为硬约束，而不是通过大权重罚项近似。
- 在满足相位约束的前提下，最大化透射率 `T = |t(f0)|^2`。
- 保持设计变量、滤波和投影流程可端到端使用 JAX 梯度。

本阶段只处理二维 TMz 标量场；三维偏振、宽带相位响应和多频色散不作为本目标的验收条件。

## 2. 数学定义

在透射监视面上，使用相同源、时间窗、采样时间和监视位置，计算：

```text
t(f0) = a_device(f0) / a_reference(f0)
T(f0) = |t(f0)|^2
```

其中 `a_reference` 来自空单元参考仿真，`a_device` 来自待优化器件。二维示例当前只有按 x 平均的 `Ez` 探针，因此该平均量可作为零阶透射幅度。

180° 相位不直接通过 `angle(t)` 约束。使用只在该相位为零的残差：

```text
c_eq(t) = 1 + Re(t) / |t| = 0
```

该残差把复透射系数推向负实轴，且不随透射幅度缩小。`t=0` 时相位没有定义，因此还需要最小幅度不等式，避免零透射被当成可行解。

建议的约束向量：

```text
c_eq(x)   = 1 + Re(t) / |t|
c_phase(x) = |t| - epsilon_amp            >= 0
c_power(x) = 1 - |t|^2                   >= 0
```

优化的主目标为：

```text
minimize  -|t|^2
subject to c_eq(x) = 0
           c_phase(x) >= 0
           c_power(x) >= 0
           0 <= rho <= 1
```

`epsilon_amp`、相位容差和功率容差必须作为显式参数暴露，不能隐藏在目标函数里。

## 4. 验收标准

- [x] 相位约束由优化器显式执行，不以固定的大权重罚项代替。
- [x] 最终解的相位误差在配置容差内；当前示例约 `0.001°`。
- [x] 最终解满足 `epsilon_amp > 0`，排除零透射时相位未定义的伪可行解。
- [x] 最终透射率不高于物理上界，并相对于同一优化器的可行初始点有所提高。
- [x] 优化器结果中同时包含目标值、约束残差、历史和成功/失败状态。
- [x] 示例可以直接运行，并在约束不可行时给出明确诊断。
- [x] 文档说明 `+180°` 与 `-180°` 当前按模 `2π` 不区分。
